# Marathon Security — Premium Landing Page Concept

Independent frontend demonstration prepared by **Euonus IT** for Marathon Security (Zetouch Security Services Pvt. Ltd.).

This project is **not** connected to the live Marathon Security website, hosting, DNS, or backend.

Reference site: https://marathonsecurity.in/

## Stack

- React + Vite + TypeScript
- Tailwind CSS v4
- Lucide React

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Notes

- Enquiry form is demo-only and does not transmit data to a server.
- Testimonials and client names are taken from publicly listed information on the reference website.
- Case studies are clearly labelled sample layouts.
